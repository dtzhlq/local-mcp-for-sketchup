# Local MCP for SketchUp

Version **0.2.0** — Apple Silicon Mac and SketchUp 2026.

An independent local MCP server for reviewed, editable SketchUp modeling. The single-image path accepts direct multimodal understanding, optional raster helpers, explicit hidden-geometry assumptions and reviewed PartGraphs across buildings, interiors and products. PhotoMatch and automatic axis detection are optional, not prerequisites.

[Download 0.2.0](https://github.com/dtzhlq/local-mcp-for-sketchup/releases/tag/v0.2.0) · [Install / rollback](docs/INSTALL.md) · [Image structure](docs/IMAGE_STRUCTURE.md) · [Acceptance and limits](docs/RELEASE_ACCEPTANCE.md) · [44 tools](docs/tool-registry.md)

The signed RBZ and bundled Node service were used for three native model deliveries: building 1108 groups, interior 397 groups, product 33 groups. All were saved, closed and reopened. These are editable approximate reconstructions with explicit relative scale and completion assumptions, not single-photo measured replicas.

The RBZ has an independent SketchUp signature. Extension Warehouse declined publication of this external MCP; signing does not mean Warehouse availability or official endorsement. No Windows or SketchUp 2025 acceptance is claimed.

Existing ALMA environment variables, Ruby namespace and compatibility commands remain intentional. Use the release's signed RBZ rather than manually copying source plugin files.
