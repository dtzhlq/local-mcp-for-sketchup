# CAD 曲面内核升级

基线：d895706；独立分支 codex/cad-surface-kernel。用户确认 NURBS 与曲面交界倒角两项并重。

## 交付目标

- 真正的有理 B-spline 曲面：次数、控制点、权重、节点及多重度；保留参数供后续修改。
- CAD B-rep 实体与布尔求交后的曲边圆角；明确半径和选边，失败不修改原模型。
- 参数源与 SketchUp 网格保持关联；已有网格被手工改动后，拒绝直接用旧参数覆盖。
- 复用现有创建、局部编辑、程序、审批、版本和事务路径；不开放任意 CAD 内核脚本。
- 原生使用一个专用 SKP 集中验证 NURBS、曲面交界圆角、参数更新、失败回滚和持久化。

## 实施顺序

1. 内核可行性：本地 WebAssembly，验证有理曲面和曲边倒角，不依赖 Python 或云端计算。
2. 受限参数合同、预算与进程隔离；精确模型参数保留，生成带误差参数的 SketchUp 网格。
3. 公共创建入口及程序 SDK；对象参数回读、局部更新和过期关联拒绝。
4. 集中离线验证，再集中原生验证，更新可安装候选包及证据。

## 边界

“任意曲面倒角”是方向，不承诺任何半径和任意退化拓扑都可成功。优先支持有精确参数来源的曲面/实体；仅有面片的历史 SKP 不冒充已恢复的精确曲面。曲面重建须有独立误差验收。

## 当前进度

已接入公共创建、局部参数更新和程序 SDK，顶层工具保持 48 个。离线测试及同一专用 SKP 的曲面生成、曲边圆角、三阶段参数更新、不可行输入拒绝、手工编辑后旧参数拒绝均已通过。服务包与 RBZ 已生成，并逐文件确认与当前源码一致。

首次保存重开暴露法线浮点末位引起的参数关联误报；指纹 v2 修复已通过离线回归和真实前后快照比较。修复后的原生重开复验因 Mac 锁屏尚未完成，不能标为完整验收。详细证据与候选包路径见 acceptance-report.json。
