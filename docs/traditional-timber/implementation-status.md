# 中式古建 v0.4.0 实施与验收

v0.4.0 在 Apple Silicon macOS、SketchUp 2026 上完成一个来源限定的《营造法式》殿堂示例：五间、十架椽、单槽、四阿顶，带副阶。旧 `song-study-v1` 仍是研究原型，不作为准确复原改名发布。

## 实现范围

- 规则包冻结本预设使用的侧样、构件、材份、尺制和来源边界。`chi_mm` 是显式工程输入；文献规定、推导、项目选择和简化分别标注，见 [规则说明](RULES.md)。
- 整屋包含柱网、升起侧脚、内外柱、梁架、槫列、柱头及补间和转角铺作、直檐与翼角、望板、瓦面、正垂脊、鸱尾。前明间双扇版门、其余四间破子棂窗、后侧素面围护、副阶敞开是项目选定布局。
- 通过既有 MCP Gateway 查询参数、创建、修改指定根实例和交付。创建记录固定规则版本、内容哈希和解析参数；调参复用未变定义，提交后中断从原任务收尾，不重复写入。
- `light` 瓦面保留可见搭接，删除隐藏背面和重复搭接面；`surface` 用连续瓦垄减少横缝。连续曲面的内部网格线柔化。总览尺度下，`light` 的真实瓦缝仍显密集，可在远景编辑时选择 `surface`；离线面数下降不等于已测得帧率提升。
