# MCP Tool Registry

> Generated by `npm run tool-registry:sync` from the shared stdio/HTTP tool registry. Do not edit this table by hand.

Current tool count: **48** (**43** retained expert tools + **4** Agent Gateway tools + **1** Session Contract tool). This is not the safe JSON DSL operation count and does not claim complete SketchUp API coverage.

The effect class is also consumed by HTTP timeout handling. New tools default fail-closed to `persistent_or_unknown` until explicitly classified as `none`.

| # | Tool | Effect class | Contract summary |
|---:|---|---|---|
| 1 | `query_model_geometry` | `none` | Read revision-bound vertices, edges, faces, loops and occurrence transforms for specified model contexts. Returns a compact summary and immutable resource handle; detail=full is explicit. Read-only. |
| 2 | `measure_model_geometry` | `none` | Measure actual geometry length, area, closed volume, minimum distance or direction angle. Returns units, method and revision. Invalid or over-budget measurements are unavailable, never bbox substitutes. |
