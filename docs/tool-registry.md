# MCP Tool Registry

> Generated by `npm run tool-registry:sync` from the shared stdio/HTTP tool registry. Do not edit this table by hand.

Current tool count: **36**. This is not the safe JSON DSL operation count and does not claim complete SketchUp API coverage.

| # | Tool | Contract summary |
|---:|---|---|
| 1 | `get_docs` | Return progressively scoped safe SketchUp documentation by topic and detail level. |
| 2 | `get_workflow_bundle` | Return recommended inspector, modeler, and QA reviewer workflows for safe SketchUp MCP use. |
| 3 | `get_capabilities` | Return runtime capability descriptors, using a live SketchUp plugin handshake for queue runtime. |
| 4 | `queue_diagnostics` | Inspect local queue directories, pending requests, orphan responses, and queue lock state without sending a SketchUp request. |
| 5 | `prepare_image_modeling_brief` | Validate path-based image-structured artifacts and prepare a review-aware MCP modeling brief. Returns compile permission and blockers; it does not call SketchUp. |
| 6 | `compile_reviewed_part_graph` | Compile schema-valid, review-cleared image artifacts and a reviewed PartGraph to a safe JSON DSL preview. It never executes the DSL or calls the queue runtime. |
| 7 | `prepare_existing_model_edit` | Inspect and fingerprint the open model, validate persistent entity targets, classify edit risk, and write a reviewable edit plan without modifying geometry. |
| 8 | `apply_reviewed_model_edit` | Apply an approved existing-model edit plan only when the live model revision still matches, then write before/after, diff, QA, review, and model artifacts. |
| 9 | `build_model` | Build model geometry from a safe JSON DSL string and return a structured snapshot. |
| 10 | `compile_expert` | Compile a restricted Expert Mode script into the safe JSON DSL without building geometry. |
| 11 | `compile_python_sdk` | Compile restricted official-style Python SDK facade code into the safe JSON DSL without executing Python. |
| 12 | `build_expert_model` | Compile a restricted Expert Mode script into JSON DSL, then build it with the selected runtime. |
| 13 | `reset_model` | Reset the current model session and return an empty snapshot. |
| 14 | `save_model` | Save the current model session and return a file path plus snapshot. |
| 15 | `save_model_version` | Save the current model session to a versioned file path without overwriting the requested base path. |
| 16 | `open_model` | Open an existing model into the selected runtime. Queue opens SKP files; mock opens saved mock JSON artifacts. |
| 17 | `import_model` | Import an external model into the current session and return the updated snapshot. |
| 18 | `export_model` | Export the current model session to a runtime-supported file format. |
| 19 | `get_model_info` | Return active model totals, bounding box, materials, tags, components, scenes, and warning summary. |
| 20 | `list_entities` | List top-level groups and component instances with stable ids, names, kinds, bbox, material, tag, and metadata. |
| 21 | `inspect_model` | Inspect the active model and optionally include filtered entity summaries and the full snapshot. |
| 22 | `adopt_open_model` | Assign stable Alma references and recursively index persistent occurrence paths for safe, policy-gated existing-model editing. |
| 23 | `resolve_model_targets` | Resolve a natural-language or filtered target request against the active model and return stable target references for selection or iteration. |
| 24 | `get_selection` | Return the current active selection as stable entity summaries. |
| 25 | `analyze_selection_geometry` | Interpret the current selected Face/Edge/Group geometry into measured primitives, ordered face loops, oriented road graphs, approach/intersection relationships, and semantic hypotheses such as road segment or junction candidate. This is an analysis layer and should not be treated as confirmed domain truth without confidence checks. |
| 26 | `plan_modification_intent` | Turn the current target resolution, selection, and interpreted geometry into an auditable ModificationIntent before optional patch execution. |
| 27 | `set_selection` | Set, add to, remove from, or clear the current active selection by stable ids or names. |
| 28 | `capture_view` | Capture the current live SketchUp viewport to an image artifact and return camera/model metadata. |
| 29 | `run_ruby_expert` | Debug-only queue tool for running arbitrary SketchUp Ruby. Disabled unless ALMA_SKETCHUP_ENABLE_RUBY_EXPERT=1 is set in both Node and SketchUp plugin environments. |
| 30 | `evaluate_py` | Official-shaped controlled evaluate_py compatibility layer. Executes JSON DSL, restricted Python SDK facade code, or restricted Expert Mode; arbitrary Python is intentionally blocked. |
| 31 | `build_report` | Build or inspect a model and write a bundled artifact report with snapshot, model info, optional QA, save artifact, and optional capture. |
| 32 | `iterate_model` | Inspect the active model, apply an incremental patch or safe ModificationIntent, then write before/after snapshots, diff, QA, optional saved model, and optional queue capture artifacts. |
| 33 | `compare_snapshots` | Compare two structured snapshots and return a diff report. |
| 34 | `compare_model` | Build the same DSL with two runtimes and return a snapshot parity QA report. |
| 35 | `validate_model` | Build or inspect a model snapshot, run semantic layout QA, and return orthographic SVG/HTML previews plus correction suggestions. |
| 36 | `validate_reference_model` | Build or inspect a model snapshot, run reference visual QA against orthographic silhouette/keypoint/area rules, and return PartGraph-targeted correction suggestions. |
